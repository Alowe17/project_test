## Задание по предмету "Интеграционное тестирование. Основы автоматизации тестирования". <br>

### Как проверить: <br>
- Выполните изменения в работе проекта (например, добавьте логику, контроллер, сущность или любое другие изменение кода) <br>
- Выполните коммит на github <br>
- Зайдите в раздел 'actions' <br>
- Выберите ваш последний коммит <br>
- Нажмите на кнопку 'Re-run jobs' и подождите немного <br>
- Ознакомьтесь с результатами <br>

### Задачи: <br>
- Выберите проект (используем наработки, учебные проекты, открытые доступные проекты). <br>
- Настройте CI/CD конвейер для проекта, который будет автоматически запускать интеграционные тесты при каждом изменении в кодовой базе. <br>
- Выполните изменения в проекте и убедитесь, что настроенный конвейер корректно выполняет тесты и фиксирует результаты. <br>
- Подготовьте отчет, в котором опишите процесс настройки конвейера, результаты выполнения тестов. <br>

### Стек: <br>
- Spring Boot
- Java 21
- MySQL
